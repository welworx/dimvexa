# Code of Conduct

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful and constructive. Assume good faith, argue about the code and the data, not
about people, and welcome newcomers. Harassment, discrimination, personal attacks and
publishing others' private information are not acceptable.

## Enforcement

Maintainers may remove comments, commits and contributions that violate this code and may
ban contributors who do so repeatedly. Report concerns privately to the maintainers through
GitHub's private channels.
