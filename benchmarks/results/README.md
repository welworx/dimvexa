# results/

Raw result files (`<library>-<version>.json`, schema `dimvexa.bench.result/1`) are written here by
the runners and published as workflow artifacts. **No real result has been committed yet**: the
runners have not been run against the competitor libraries. Do not add files here by hand, and do
not commit files produced with `--quick` (a smoke test, not a measurement). Fixture data for
testing the report generator lives in `benchmarks/fixtures/` and is clearly named.
